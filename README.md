# Coffee Shop Landing Page

A modern, responsive web application for a coffee shop, featuring a seamless integration between a WordPress backend and a custom React frontend.

## Key Features:

- **Responsive Design**: Fully adaptive layout, mobile-first approach.
- **Modern UI**: Crafted with Tailwind CSS for high performance and clean aesthetics.
- **WordPress Integration**: Uses WordPress as a robust CMS for easy content management.

## Tech Stack:

- **Frontend**: React.js, Tailwind CSS
- **Backend**: WordPress(Headless CMS)
- **Deployment**: Vercel
